# The old Claude kit (archived 2026-09-28)

The project skills (spec, build, qa, ship, status, repro, with the Motion
sync), the kit-* agents and the guard hook that Pro Moves ran on before the
engine. The engine was extracted from this kit, and Pro Moves now runs on
the engine plugin instead (see `.engine/`).

Kept here only as a fallback. Nothing in this folder is loaded by Claude. To
bring a piece back, move it to the same path under `.claude/`.
